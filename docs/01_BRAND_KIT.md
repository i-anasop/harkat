# 01 · Harkat Brand Kit

## Identity
- **Name:** Harkat (open question: whether to add "AI")
- **Tagline:** *Your motion team, without the agency.*
- **Hero line:** *Product films that move.*
- **Logo:** 5-blade swirl mark (motion, a turbine) + lowercase **"harkat"** wordmark. Mark = blue `#2E4BDB`; wordmark = ink `#0D1222`.

## Colour (single hue: blue)
| Role | Hex |
|------|-----|
| Background | `#F6F7F9` |
| Ink | `#0D1222` |
| Muted | `#5B6275` |
| Cobalt (primary) | `#2E4BDB` |
| Deep | `#1F33B0` · `#16258A` · `#0B1340` |
| Light | `#4F6CEB` · `#7F96F4` · `#B8C6FB` · `#DCE4FF` |

- **Gradients:** grainy radial blue (deep → cobalt → periwinkle).
- **Theme:** light first, always. No dark/bold concepts for the site.

## Type
- **Geist** 500–600 for headings, tight tracking about −0.055em.
- **Geist Mono** for small labels.
- (Pond client films use the client's font. See the client notes.)

## UI
- **Primary button:** black, with a blue gradient "tail" holding an arrow.
- Minimal, clean UI. Real logos only.

## Motion personality
Fast, detailed, no fades-to-black. Masked letter reveals, match cuts, a living UI wall (columns moving in alternate directions), orbit rings of real logos, blob portals. All 2D.

## Website direction
Simple, clean, minimal, light. Inspired by joinpond.ai's professionalism but **not a replica**. Shows results (case studies) and a motion-graphic "about us" video. Hosted on Cloudflare Pages (domain TBD).
