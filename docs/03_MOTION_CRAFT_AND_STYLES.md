# 03 · Motion Craft & Styles

## Core craft rules
1. Text work and transitions are the two things that make a video. Learn each round, never repeat a mistake.
2. **"Best text transition work"** (GenLayer reference style): words appear one at a time, fading grey → ink. The line stays centred, text sits beside the visual. The fixed part stays anchored; only the changing word swaps in place (e.g. "Built for" stays, the right word swaps).
3. **Placement rule (overrides re-centring):** new text appears in its final spot without displacing text already on screen. Alignment stays fixed and the scene stays still until the camera moves.
4. **"Butter transitions"** (Gemini reference style): clean, smooth scene-to-scene movement. Use for all moves (up/down, left/right).
5. **Storytelling:** problem in one line in one clip → product → show how it solves it.
6. Start iterations from a high-quality v1.

## Lessons learned
- Copy the reference's structure and motion closely from the start. Don't loosely interpret.
- But the result must not look *completely* copied: add our own creative content and the client's theme.
- Every box or card needs real, rich UI content. Empty or generic tiles get rejected.
- Keep claims factual.
- Avoid AI-looking icons and sparkles. Use real logos and agent cards instead.
- No scramble/hash text effects. Use smooth text transitions.
- Hold key content long enough to read.
- One consistent font. No serif or mono mixing inside a film.
- Don't mix dark and light mid-film: a few dark clips at the start up to the logo reveal, then one consistent light theme to the end.
- Minimal backgrounds: no logo marks or glow clouds behind content.
- Final clip: clean URL only, small, no underline, appears straight away (no rise).

## Style library
Each pro reference video Anas shares becomes a named style. To apply one: copy it ~100% (frame-by-frame transitions, SFX use, type, structure), then swap in the client's theme colours, font and our own content.

### "Pratham style" (pratham.mp4: Ramp expense-platform promo)
32 s · 1080p · 30fps · SFX only (no music).
- Opens on a grid of outlined squares that flicker in, with a highlighted-word text block typing letter by letter.
- Grid floods to a light paper ground with a bracketed search field typing.
- Clean grotesk sans. Mixes filled words, thin outline words and highlight blocks.
- UI as stacked cards and dashed icon tiles floating.
- Logo reveal by line-draw, then fill, then a gradient wash.
- Nodes-and-wires flow diagrams with dots and labels.
- Bracket corners scanning a receipt. Marquee of cards.
- Huge word swap, then a small line. Hub-and-spoke icon network. Word carousel beside the logo.
- Ends on a solid brand-colour end card.
- SFX sparse and sharp: clicks, ticks, typing keys, a few low thuds, short whooshes, timed to each visual event.

### Pratham-style learnings from the Pond build (v2 → v5)
- Agent cards stack like stairs, with real brand logos.
- Workflow scene (n8n-style): slow, show the full architecture, pause when complete, hold the title first.
- Show 5–6 agent boxes and pause when all are visible.
- Perks boxes as a slideshow that stops and centres on each box.
- Hub scene: just the logo centred, tall narrow agent cards orbiting in an oval. No box, no connecting lines.
- "For Every Task" is its own clip, words arriving one by one.
