# 05 · Quality Checklist (run before every delivery)

## Hard rules
- [ ] **No music** anywhere. Audio is SFX only.
- [ ] **No women** in any image or photo. Avatars are abstract or initials.
- [ ] **No 3D**, tilted planes or iris wipes.
- [ ] **Real logos** from official SVGs. No letter placeholders.
- [ ] Every claim and number is real or clearly sample data.
- [ ] Client is halal.

## Motion
- [ ] Hook lands in the first 3 s
- [ ] Transitions are smooth ("butter"). No jitter.
- [ ] New text never shifts existing text
- [ ] Key content is held long enough to read
- [ ] Camera only moves on transitions and kinetic text

## Design
- [ ] One font, one hue, one theme (light after the logo reveal)
- [ ] Every card has real, rich UI. No empty tiles.
- [ ] Minimal backgrounds
- [ ] Final clip: clean URL (the CTA)

## Technical
- [ ] 30–40 s, rendered cleanly (60fps if smoothness needed)
- [ ] ffmpeg `crf ~20`, file roughly 10 MB
- [ ] SFX peaks on cuts, mixed to about −22 dBFS
- [ ] No secrets or credentials in the repo

## Delivery
- [ ] Only the requested changes were made
- [ ] Short summary to Anas: what changed, what to check
